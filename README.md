- **일별 생산계획안 생성 PoC** — 매주 갱신되는 SAP 판매계획을 바탕으로 일별 생산품목과 생산량을 편성하는 2단계 CP-SAT 모델. 단일 라인·4개 제품 범위에서 과거 90일 중 제품과 생산량이 모두 일치한 날의 비율은 약 78%였습니다.
- **보일러 SOx 약품 투입량 최적화 가이드** — 배출기준을 지키면서 과투입을 줄일 수 있는 기준값을 제공하는 운전 지원 서비스. 제어 시스템과 분리해 보드 운전원이 최종 투입량을 결정하며, 2026년 6월부터 정식 운영하고 있습니다.
- **건조설비 이상 징후 탐지 PoC** — 운전자 인터뷰에서 확인한 온도 패턴과 다변량 센서 모델을 결합했습니다. 과거 고장 사례에서는 징후를 10~15분 앞서 포착했지만, 오탐이 많아 현장에서 지속적으로 사용하기 어렵다고 판단해 PoC로 마무리했습니다.
